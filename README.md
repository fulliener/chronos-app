## О проекте

Мобильное приложение на Flutter для учёта рабочего времени с модулем предиктивной аналитики. Работает полностью офлайн — данные хранятся локально в SQLite, регистрация аккаунта не требуется.

### Ключевые возможности

- **Таймер учёта** — запуск/остановка сессии, выбор категории, ретроспективная запись
- **Аналитика** — круговая диаграмма по категориям, почасовая активность за день/неделю/месяц
- **Прогноз целей** — линейная аппроксимация: когда будет достигнута недельная цель
- **Детектор выгорания** — пороговый анализ: если работа > 9 ч/день три дня подряд
- **«Золотой час»** — алгоритм скользящего суммирования для поиска пика продуктивности
- **Push-уведомления** — напоминание о перерыве, достижение цели
- **Тёмная тема** — минималистичный графитовый дизайн (#121212)
